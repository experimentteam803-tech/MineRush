Frequently asked questions

How do I download MineRush?

Tap any Download button. Once you set the GitHub Release URL in this page's configuration, it will open the APK download directly.

Is earning or withdrawal guaranteed?

No. This landing page does not promise earnings. Mining rates, coin conversion, task availability, withdrawal minimums and payout processing depend on the app's current configuration and applicable terms.

Why does Android ask me to allow installation?

If you install an APK outside the Play Store, Android may ask you to allow your browser or file manager to install unknown apps. Only install APKs you trust and verify that the file came from your official release.

Where can I get help?

Update the support link in the page configuration to your official MineRush support channel before publishing.
